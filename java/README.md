# OpenAI TTS Java SDK for RunAPI

Install the SDK:

```kotlin
implementation("ai.runapi:runapi-openai-tts:0.1.0")
```

Create `OpenaiTtsClient` and call `client.textToSpeech().run(...)`.

Model details and pricing: https://runapi.ai/models/openai-tts
