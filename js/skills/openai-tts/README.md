## Install

```bash
npx skills add runapi-ai/openai-tts -g
```

Or paste this prompt to your AI agent:

```text
Install the openai-tts skill for me:

1. Clone https://github.com/runapi-ai/openai-tts
2. Copy the skills/openai-tts/ directory into your user-level skills directory for Claude Code, Codex, or Gemini CLI.
3. Verify that skills/openai-tts/SKILL.md is present.
4. Confirm the install path when done.
```
